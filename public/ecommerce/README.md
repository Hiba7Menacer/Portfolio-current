# HB Creations — Handmade Jewelry E-Commerce

A fully functional e-commerce website for **HB Creations**, a handmade jewelry brand. Built with **HTML, CSS and vanilla JavaScript**.

## Features
- Product catalog with categories (bracelets, necklaces, sets)
- Single product pages with image galleries
- Persistent shopping cart using `localStorage`
- Coupon codes: `HB10` (10% off) and `HB20` (20% off)
- Fully responsive layout
- Contact / about pages

## Live demo
Try it live: https://portfolio-v0-five-phi.vercel.app/ecommerce/index.html

## Pages
- `index.html` — Home
- `shop.html` — Shop
- `sproduct.html?id=pX` — Single product
- `cart.html` — Cart
- `about.html` — About
- `contact.html` — Contact

## Run locally
Just open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```
